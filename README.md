# Сравнение поставщиков

Лёгкое нативное приложение macOS от ANODHAS AI для сравнения коммерческих предложений по одинаковой закупке.

Произвольные поставщики, товары, характеристики, артикулы и единицы измерения. Работает локально без сервера, браузерной оболочки, сторонних библиотек, сетевых прав, платной модели и фоновой службы.

[Скачать для Mac](https://github.com/zakras030997-byte/anodhas-supplier-compare/releases/tag/v1.0.0) · [Исходники под MIT](LICENSE)

Приложение 1.0.0 занимает около 3,2 МБ, установочный DMG — около 1,3 МБ. Сборка Universal для Apple Silicon и Intel, macOS 13 и новее. Скачайте DMG из релиза, откройте его и перенесите приложение в «Программы». SHA256 опубликован рядом с установщиком.

## Начало

Нажмите «Новая закупка», задайте товары и потребность. Во вкладке «Предложения» заполните общие условия поставщика и строки цен. При разных единицах укажите коэффициент, при разных валютах — курс, дату и источник. Подтвердите соответствие товара, объёма и условий. Дополнительная кнопка «Пример закупки» позволяет изучить заполненный вариант.

Во вкладке «Сравнение» видно:

- минимальную стоимость среди подходящих предложений, раннюю дату и минимальную предоплату отдельно;
- стоимость товарных строк, доставку, общие сборы, итог и причины исключения;
- ручной вариант из разных поставщиков с повторным расчётом перевозки каждого заказа.

Просроченное КП, нарушение обязательного срока/предоплаты, недостаточный объём, неизвестные расходы и неподтверждённые строки не объявляются подходящим вариантом.

Суммы считаются отдельным Decimal-модулем. Минимум и шаг закупки могут создавать излишек; он показан. Скидка применяется к товарной строке. Включённый НДС не добавляется повторно, НДС сверху требует ставки. Доставка и сборы вводятся окончательными суммами с их налогами в валюте КП. Округление half-up по строкам в базовой валюте; точность задаётся для закупки. Возмещение налогов и неуказанные расходы не рассчитываются.

## Таблицы и резервная копия

В выбранном предложении нажмите «Импорт CSV / Excel». Можно открыть UTF-8 CSV/TSV либо вставить таблицу из Excel. Выберите колонки товара/артикула, цены и единицы. Пример:

    Артикул;Цена;Единица
    CAB-01;520;м
    LGT-01;650;шт.

Сопоставление выполняется по уникальному точному артикулу/названию либо вручную. Дубли одного товара блокируют применение. Импорт заменяет только показанные строки, сбрасывая их проверку и НДС для повторного просмотра. До 200 записей и 1 МиБ на импорт.

Панель выгрузки в разделе «Сравнение» экспортирует:

- сводку поставщиков CSV и отдельные позиции CSV;
- статический печатный HTML-отчёт без скриптов и внешних ресурсов;
- JSON-закупку для переноса и резервной копии. Открытие JSON добавляет отдельную копию.

Цены принимают запятую или точку, до 6 дробных знаков и корректные пробелы тысяч. Валюта — три латинские буквы. Даты — ГГГГ-ММ-ДД. Источники КП записываются в поля и отчёт как текст, не исполняются.

Состояние сохраняется атомарно в собственном sandbox-контейнере приложения. При ошибке чтения существующий файл не затирается. Лимиты рабочего пространства: 100 закупок, 200 товаров и 50 поставщиков в одной закупке.

## Сборка

macOS 13+, Swift и совместимый Apple SDK, инструменты командной строки Apple.

    bash Scripts/test.sh
    bash Scripts/build.sh
    bash Scripts/package.sh

При необходимости задайте SUPPLIER_COMPARE_SDK=/путь/к/MacOSX.sdk. Сборка создаёт Universal arm64/x86_64. Для собственного Developer ID предусмотрен SIGN_IDENTITY; нотарификация выполняется отдельно владельцем сертификата. По умолчанию подпись локальная, политика другого Mac может ограничить запуск.

## Границы 1.0

Нет автоматического разбора PDF/XLSX, нечёткого объединения товаров, автоматических курсов валют, скрытого общего рейтинга, глобального оптимизатора корзины, налоговых вычетов, покупки и отправки поставщикам. Вставка таблицы из Excel поддерживается без чтения самого XLSX-файла.

Заполненный пример можно заменить своими закупками и предложениями. Universal-сборка не заменяет проверку на другом Mac или старой macOS.

Техническое задание и контрольные сценарии находятся в SPEC.md. Исходники самостоятельные; изученный сторонний код в приложение не переносился. MIT.
